# Bites of Python

A collection of bite-sized Python exercises and examples covering various programming concepts.

## Overview

This repository contains a series of numbered directories, each containing focused Python exercises that demonstrate different programming concepts, from basic operations to more advanced features.

## Structure

Each numbered directory contains a specific Python exercise:
- Basic operations (summing, division)
- Data structures (lists, dictionaries)
- String manipulation
- Object-oriented programming concepts
- Functional programming patterns
- And more...

## Getting Started

1. Clone this repository
2. Navigate to any numbered directory
3. Run the Python files to see the exercises in action
4. Study the code to understand different Python concepts

## Examples

- `1/summing.py` - Demonstrates default parameters and range operations
- `15/enumerate_data.py` - Shows enumerate usage
- `19/simple_property.py` - Basic property decorators
- `43/kwargs.py` - Keyword arguments handling

## Learning Path

These exercises are designed to be worked through sequentially, with each building upon previous concepts. They're perfect for:
- Python beginners looking for hands-on practice
- Developers wanting to review specific Python features
- Anyone interested in bite-sized coding exercises

## Contributing

Feel free to add your own exercises or improve existing ones. Each exercise should be:
